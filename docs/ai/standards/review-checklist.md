# Review Checklist

## Code

- Đúng mục tiêu task.
- Không phá flow cũ.
- Không duplicate logic không cần thiết.
- Không hardcode secrets mới.
- Logging an toàn.

## Business

- Không vi phạm business rules trong `docs/project`.
- Nếu docs legacy mâu thuẫn source, đã nêu conflict rõ ràng.

## Security

- Không vi phạm `docs/ai/knowledge/security-boundary.md`.

## Test

- Có test phù hợp hoặc ghi rõ testing gap.
